⚡ **生产级导出，现在快至一分钟内：即使作品里的字体或图片迟迟没有响应，Open
Design 也不会再让整个流程卡上十分钟，而会在有限等待后继续完成图片或 PDF 交付。**
已经打开的 HTML 预览会保留现场，首次配置也只会在真正连通后放你继续。同时，
Go Plan 上线后的定价、权益标识与升级路径经过一轮细致校准，让“当前套餐是什么、
还能升级到哪里、点击后会去哪里”都变得更可信。

## ⚡ 性能与可靠性

- 📤 **卡住的导出，从十分钟等待缩短到一分钟内继续交付。** 作品里的字体或图片如果
  一直加载不回来，Open Design 会结束无意义的等待，继续完成图片或 PDF 导出；正常
  加载的作品仍保持完整质量，真正失败时也会留下具体原因，方便继续定位。 (#7182)
  感谢 @lefarcen。

- 🖥️ **回到已经打开的 HTML 预览，现场还在。** 项目切换、文件标签切换以及
  Preview/Code 切换不再触发多余的空白闪烁或整页重载；滚动位置、实时文档和编辑
  结果会被保留，文字修改在保存后立即出现。 (#7156) 感谢 @lefarcen。

- ✅ **明明已经产出文件的任务，不再被误判为“没有交付物”。** 浏览器偶尔没来得及
  同步文件时，Open Design 会以 daemon 最终确认的产物为准；真正零产出的任务仍会
  保留原来的错误提示。 (#5750) 感谢 @ferrarifankid04。

- 🧩 **项目预览中的交互脚本不再被资源地址改写误伤。** 内联脚本会原样送达，CSS 与
  其他资源仍保持工作区隔离，依赖脚本的交互预览可以正常运行。 (#6938)
  感谢 @mturac。

## 🐛 修复

### 首次配置与运行

- 🚦 **“继续”现在代表真的准备好了。** 首次配置选择本地 CLI 时，检测到可用后按钮
  才会进入可操作状态；使用 BYOK 时，Key、Base URL 和模型填写完整后，点击继续会
  自动执行连接测试。失败或限流会留在当前页面并显示可行动的错误，只有测试成功后
  才完成配置。 (#7164) 感谢 @alchemistklk。

### Pricing、套餐与升级

- 🌐 **从什么语言进入 Pricing，就用什么语言继续。** 应用传递的语言会在页面绘制前
  生效，不再先闪出错误语言；没有显式语言的直接访问仍沿用浏览器和已保存偏好。
  (#7197) 感谢 @Siri-Ray。

- ↩️ **从哪个 Cloud Console 来，结账后就回到哪里。** 测试、功能验证和本地环境的
  Pricing 跳转会安全地返回原入口，而不是误入生产环境；无效目标会显示本地化错误
  并禁用结账，不再静默回退。 (#7219) 感谢 @nettee。

- ⬆️ **当前套餐和升级方向一眼能看懂。** 当前套餐显示 Current plan，低于当前套餐
  的选项不可点击，更高档位保留升级入口；价格节省金额、模型顺序、状态列、推荐色
  和月付/年付控件也与验收稿保持一致。 (#7191, #7222) 感谢 @Siri-Ray。

- ♾️ **“无限使用”只出现在你的套餐真正包含的模型上。** Go、Plus、Pro 和 Max 会按
  各自权益展示标签；Team 工作区不再错误继承个人套餐标识，BYOK 也不会声称平台
  不限量。付费用户余额恰好为零时不再看到没有行动意义的余额片段，但欠费、免费
  计划和 Team 仍会展示需要关注的余额。 (#7190, #7202, #7196)
  感谢 @lefarcen、@Siri-Ray。

- 低余额弹窗的操作按钮恢复统一的视觉层级。 (#7138)

### 界面与导航

- ⬇️ **更新按钮不再挤进账户胶囊。** 新版本下载完成后，绿色更新按钮会作为独立控件
  出现在头像/余额胶囊右侧，账户菜单和更新动作各归其位。 (#7237)
  感谢 @Siri-Ray。

- 🔔 **消息中心回到一张简单列表。** 已读与未读消息统一展示，不再需要筛选标签；
  未读项使用紧凑红点，打开后仍按单条标记已读。 (#7231) 感谢 @Siri-Ray。

- 🔗 **社区入口常驻左侧导航底部。** 社交链接从账户菜单移到 Home 导航栏底部；
  中文界面显示飞书群入口，其他语言显示 Discord，X 与邮件入口保持一致。 (#7232)
  感谢 @alchemistklk。
