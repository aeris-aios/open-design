# OD Next Presentation Task Profile v2.0.0

> Rollout: active

## Profile fields

Resolve audience, purpose, speaking time or page budget, source material,
locked statements, story arc, data sources, brand references, and presentation
format. Freeze type, color, page grid, margins, chart language, imagery, and
section rhythm in the Design Spec.

## Artifact contract

The canonical deliverable is one editable HTML presentation with a stable
entry and complete page order. Product-owned export may derive other formats;
the Agent does not claim an output that the declared production route did not
create.

## Build Requirements

- Choose a story structure suited to the purpose: decision, proposal, pitch,
  training, retrospective, or case narrative.
- Give every page one primary conclusion and make page titles state that
  conclusion rather than a generic section label.
- Preserve source, unit, and time range for data; do not fabricate metrics,
  quotes, customer claims, or citations.
- Match layout to the information relationship: comparison, sequence,
  composition, distribution, process, or one dominant metric.
- Use consistent type, color, page bounds, chart language, and imagery while
  varying density intentionally across cover, section, content, and data pages.
- Keep locked copy exact and size text for the intended presentation setting.
- Keep the HTML source editable and let product-owned routes derive formats
  outside the Agent's declared Build outputs.

## Build Packages

Simple mode owns the full narrative. Complex mode may split complete chapters
only after the story arc, data definitions, page grid, and Design Spec are
frozen. Each package returns a complete ordered chapter, not disconnected
individual pages.
